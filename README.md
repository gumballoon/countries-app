# REST Countries API with Color Theme Switcher - Frontend Mentor

A responsive countries explorer application with search, filtering, and dark mode functionality built with Vue 3 and Tailwind CSS.

## Challenge Overview

This project is a solution to the REST Countries API with color theme switcher challenge from Frontend Mentor. The challenge focuses on integrating with the REST Countries API to pull country data and display it with detailed information pages.

## Portfolio Project

This project also serves as a portfolio demonstration showcasing:
- **Frontend Development**: Vue 3 with Composition API for reactive component development
- **State Management**: Pinia store for managing application state
- **Responsive Design**: Mobile-first approach with Tailwind CSS
- **API Integration**: REST Countries API data fetching and processing
- **UI/UX Implementation**: Interactive elements with hover states and theme switching

## Features

- **Country Listing**: View all countries from the API on the homepage
- **Search Functionality**: Search for a country using an input field
- **Region Filtering**: Filter countries by region (Africa, Americas, Asia, Europe, Oceania)
- **Detailed View**: Click on a country to see more detailed information on a separate page
- **Border Navigation**: Click through to border countries on the detail page
- **Responsive Layout**: Optimal layout for mobile, tablet, and desktop screens
- **Interactive States**: Hover and focus states for all interactive elements
- **Dark Mode**: Toggle the color scheme between light and dark mode

## Built With

- **Vue 3** - Progressive JavaScript framework with Composition API
- **Vue Router** - Official router for Vue.js applications
- **Pinia** - State management for Vue
- **Tailwind CSS v4** - Utility-first CSS framework for styling
- **Vite** - Fast build tool and development server

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn package manager

### Installation

1. Clone the repository and navigate to the project directory
2. Install dependencies: `npm install`
3. Start the development server: `npm run dev`

## Functionality

### Core Features Implemented:

- See all countries from the API on the homepage
- Search for a country using an input field
- Filter countries by region
- Click on a country to see more detailed information on a separate page
- Click through to the border countries on the detail page
- View the optimal layout for the interface depending on device's screen size
- See hover and focus states for all interactive elements on the page

### User Actions:

1. **Browse Countries**: View all countries on page load
2. **Search**: Type in the search field to find countries by name
3. **Filter by Region**: Select a region to show only countries from that area
4. **View Details**: Click on a country card to see detailed information
5. **Navigate Borders**: Click on border country buttons to explore neighboring countries
6. **Toggle Theme**: Switch between light and dark mode for preferred viewing

- **Vue 3 Composition API**: Modern reactive component architecture
- **Dynamic Routing**: Vue Router with dynamic country code parameters
- **State Persistence**: Theme preference saved for consistent experience
